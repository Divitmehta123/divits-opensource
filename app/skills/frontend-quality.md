---
name: frontend-quality
description: Build and assess deliberate interfaces across normal, edge, and accessible interaction states.
triggers: [frontend, ui, terminal, accessibility, browser]
---
Follow the product's existing visual and interaction language rather than generic templates. Verify
loading, empty, error, long-content, narrow, keyboard-only, reduced-motion, and limited-color states.
Keep state rendering deterministic, actions discoverable, hierarchy intentional, and feedback tied
to actual runtime events. Validate the built interface in its real terminal or browser surface.
