---
name: agent-coordination
description: Decompose bounded work, delegate independent tasks, and integrate structured agent evidence.
triggers: [delegate, agents, parallel, coordinate]
---
Delegate only work with a crisp objective, explicit owned paths, measurable acceptance criteria,
and validation steps. Keep dependent tasks ordered and independent tasks concurrent. Send blockers
and interface changes to affected agents early. Wait for every required completion, verify the
reported files and checks, and integrate evidence before claiming the parent objective is complete.
